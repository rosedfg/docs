---
title: "Linux"
description: "Подключение на Linux через Happ."
---

<Steps>
  <Step title="Установите Happ">
    Скачайте пакет: [.deb](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.linux.x64.deb) для Ubuntu/Debian или [.rpm](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.linux.x64.rpm) для Fedora. Установка: `sudo apt install ./Happ.linux.x64.deb`. Альтернатива — [Incy](/connect/apps#incy).
  </Step>
  <Step title="Добавьте подписку">
    Скопируйте ссылку из бота [@matrix402bot](https://t.me/matrix402bot) и в Happ нажмите **+** → **Вставить из буфера**.
  </Step>
  <Step title="Включите TUN-режим">
    В настройках Happ включите **TUN** и выберите ядро **sing-box**. Так через VPN пойдёт трафик всех программ, а не только браузера.
  </Step>
  <Step title="Подключитесь">
    Выберите сервер и нажмите кнопку подключения.
  </Step>
</Steps>

<Info>
  Для подключения к Матрице на ПК (Windows/Linux)  рекомендуем использовать программу Happ Desktop
</Info>
