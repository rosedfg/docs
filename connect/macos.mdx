## Установка

<Steps>
  <Step title="Скачайте клиент">
    Установите [Hiddify](https://github.com/hiddify/hiddify-app/releases) — файл `Hiddify-MacOS.dmg`.
  </Step>
  <Step title="Импортируйте ключ">
    Скопируйте ссылку-ключ. В приложении нажмите **+** → **Добавить из буфера обмена**.
  </Step>
  <Step title="Подключитесь">
    Выберите профиль Matrix Network и нажмите кнопку подключения. При первом запуске разрешите добавление VPN-конфигурации.
  </Step>
</Steps>

## Проверка

Откройте [2ip.ru](https://2ip.ru) — должен отображаться IP-адрес сервера, а не ваш.
